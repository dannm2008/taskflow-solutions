# TaskFlow Solutions - Gestor de Tareas

Sistema básico desarrollado en Python para administrar tareas de forma eficiente.

## Funcionalidades
- ✅ Crear, ver y completar tareas.
- 📊 Generar reportes de estado.
- 🗑️ Eliminar tareas específicas.
- 🧹 Limpieza automática de tareas completadas.
- 💾 Persistencia de datos en formato JSON.

## Cómo usar
1. Clonar el repositorio.
2. Ejecutar `python task_manager.py` en la terminal.
